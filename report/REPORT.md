## Part 1 — Understanding the Objective

### 1.1 Unsupervised contrastive loss

For a batch of $N$ sentences, the same sentence is encoded twice with independent dropout masks, generating $h_i$ and $h_i^+$. The loss for one anchor is

$$
\ell_i =
-\log
\frac{
\exp(\operatorname{sim}(h_i,h_i^+)/\tau)
}{
\sum_{j=1}^{N}
\exp(\operatorname{sim}(h_i,h_j^+)/\tau)
}.
$$

The numerator contains the positive pair. The denominator contains the positive plus the other $N-1$ second-view sentences. With batch size 64, the unsupervised objective therefore compares each anchor against **63 in-batch negatives**.

### 1.2 Supervised objective

Supervised SimCSE uses an NLI entailment pair as the positive example and contradiction hypotheses as hard negatives. The supplied subset is not a complete triplet dataset: only a fraction of entailment pairs has a contradiction for the same premise. Therefore our implementation only inserts **real available contradictions** into the hard-negative bank; it never substitutes a missing contradiction with an entailment.

With $N$ positive pairs and $H$ real contradiction examples in a batch, each anchor is compared against:

- $N-1$ other entailment candidates; and
- $H$ contradiction hard-negative candidates.

Thus the actual number of negative candidates is $N-1+H$, not automatically $2N-1$ for this subset.

### 1.3 Temperature

The temperature $\tau$ rescales cosine-similarity logits. Smaller values make the softmax distribution sharper and place more emphasis on difficult negatives. We use $\tau=0.05$ as the main configuration.

The SimCSE paper reports substantial sensitivity to dropout and temperature-related training choices; the assignment asks us to describe these findings, not to claim unobserved behavior in our own runs.

### 1.4 SimCSE vs. Sentence-BERT

Sentence-BERT was trained with NLI supervision using a classification objective built from sentence-pair representations. SimCSE instead optimizes the geometry of sentence embeddings directly through a contrastive objective. This distinction matters for STS-B because our evaluation uses cosine similarity directly on sentence embeddings, followed by Spearman correlation with human similarity ratings.

### 1.5 Alignment and uniformity

We evaluate two geometric properties from Wang and Isola:

$$
\ell_{\text{align}}
=
\mathbb{E}_{(x,y)\sim p_{\text{pos}}}
\|f(x)-f(y)\|_2^2
$$

and

$$
\ell_{\text{uniform}}
=
\log
\mathbb{E}_{x,y\sim p_{\text{data}}}
\exp(-2\|f(x)-f(y)\|_2^2).
$$

Lower alignment indicates that positive pairs are closer. More negative uniformity indicates that embeddings are spread more broadly across the hypersphere.

## Part 2 — Data

The supplied file contains 100,000 SNLI records. From it the pipeline constructs:

- **165,529 unique sentences** for unsupervised training;
- **33,351 premise-entailment positive pairs** for supervised training;
- contradiction hard negatives only when they actually exist for a premise.

The exact hard-negative count and percentage are printed by the data loader and stored in each run's results.

For evaluation we use STS-B:

- dev: 1,500 pairs;
- test: 1,379 pairs.

Dev is used for checkpoint selection. Test is reserved for final evaluation of a completed run.

## Part 5 — Required Ablations

### 5.1 Same dropout mask

Control:
- two forward passes;
- independent dropout masks.

Ablation:
- the second representation is exactly the first representation;
- therefore both views use the same stochastic realization.

The SimCSE paper reports a large degradation for fixed dropout-mask behavior on STS-B dev. Our report must use **our measured dev/test delta**, produced by:

`report/artifacts/ablation_deltas_generated.md`

after training.

### 5.2 Hard negatives ON vs. OFF

Control:
- use all real contradiction examples available in each batch.

Ablation:
- remove contradiction candidates while keeping the rest of the configuration unchanged.

Again, the final report must copy the measured delta from generated artifacts rather than estimating it.

## Part 7 — Explaining the Gap

The paper and our setup differ in several measurable ways.

### Training-data scale

The original unsupervised SimCSE setup uses a much larger general-domain corpus, whereas our unsupervised set contains only 165,529 SNLI-derived sentences.

The supervised paper setup uses substantially more NLI supervision, whereas our supplied subset contains only 33,351 positive entailment pairs.

### Domain diversity

SNLI is dominated by image-description language, while the original unsupervised setup uses broad Wikipedia text. This reduces lexical and syntactic diversity.

### Hard-negative coverage

Only a subset of our positive pairs has a contradiction available. Therefore the effective hard-negative bank per mini-batch is smaller than in a fully paired NLI triplet setup.

### Batch size

Our supervised batch size is 64, while the original SimCSE recipe used substantially larger supervised batches. A smaller batch also means fewer in-batch negatives.

These facts can explain why a gap is plausible, but we **do not assign invented percentages** such as 70/20/10 to the causes. A causal percentage would require controlled experiments that isolate each factor.

- One seed is used, as allowed by the assignment.

- The training corpus is smaller and less diverse than the paper's original data.
