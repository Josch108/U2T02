\begin{abstract}
This report presents the implementation and evaluation of unsupervised and supervised SimCSE starting from \texttt{bert-base-uncased}. Training used the supplied 100k-record SNLI subset and evaluation used STS-B with normalized embeddings, cosine similarity, and Spearman correlation. The required ablations were also performed. The strongest model was supervised SimCSE, reaching 82.29 dev and 78.32 test Spearman. The selected model was published to the Hugging Face Hub and reproduced the same test score after reloading.
\end{abstract}

\begin{IEEEkeywords}
SimCSE, sentence embeddings, contrastive learning, BERT, STS-B, Hugging Face
\end{IEEEkeywords}

\section{Introduction}
BERT produces strong token representations, but directly pooled BERT vectors do not necessarily form a useful sentence embedding space. SimCSE improves sentence representations through contrastive learning. In the unsupervised variant, the same sentence is encoded twice and independent dropout creates two positive views. In the supervised variant, entailment pairs provide positives and contradiction hypotheses can act as hard negatives \cite{gao2021}.

\section{Data and Methodology}
The supplied \texttt{snli\_train\_100k.jsonl} contains 100,000 SNLI records. From it, the pipeline produced 165,529 unique sentences for unsupervised training, 33,351 premise--entailment pairs for supervised training, and 9,488 positive pairs with a real contradiction hard negative (28.45\%). STS-B was used for evaluation with 1,500 dev pairs and 1,379 test pairs.

\subsection{Unsupervised Objective}
For a batch of $N$ sentences, the same sentence is encoded twice with independent dropout masks:
\begin{equation}
\ell_i=-\log\frac{\exp(\operatorname{sim}(h_i,h_i^+)/\tau)}{\sum_{j=1}^{N}\exp(\operatorname{sim}(h_i,h_j^+)/\tau)}.
\end{equation}
With batch size 64, each anchor is contrasted against 63 ordinary in-batch negatives.

\subsection{Supervised Objective}
The supervised variant uses premise--entailment pairs as positives and real contradiction hypotheses as hard negatives. Missing contradictions are not replaced with entailment examples. For a batch with $N$ positive pairs and $H$ available contradictions, each anchor has $N-1+H$ negative candidates.

\section{Similarity Distribution and Retrievals}
For the supervised model, mean cosine similarity increased with the human STS-B score: 0.531 for score bin 0--1, 0.747 for 1--2, 0.813 for 2--3, 0.871 for 3--4, and 0.931 for 4--5.

A successful retrieval example used the query ``A man sings with a guitar.'' The top neighbor was ``A man is singing while playing the guitar.'' with cosine 0.9730.

A representative failure used the query ``The man is mixing whipping cream.'' The nearest neighbor was ``A man is cutting pieces of butter into a mixing bowl.'' with cosine 0.7626. The sentences share a cooking context but describe different actions, showing that the model can over-weight topical similarity.

\section{Gap with the Paper}
The original SimCSE paper reports 82.50 dev / 76.85 test for unsupervised BERT-base and 86.20 dev / 84.25 test for supervised BERT-base \cite{gao2021}. Our training corpus is substantially smaller, contains only 33,351 supervised positives, has hard negatives for only 28.45\% of them, and uses batch size 64. These differences explain why a performance gap is plausible, but the experiment does not support assigning causal percentages to individual factors.

\section{Hugging Face Publication}
The selected supervised model was published at:

\url{https://huggingface.co/zakerzel/upy-u2t02-simcse-supervised}

The recorded checkpoint test Spearman was 78.318091. The exported model scored 78.318097. After upload and reload from the Hub, the score remained 78.318097, producing a Hub reload delta of 0.000000. This verifies numerical reproduction of the published model.

\section{Limitations}
Only one seed was used for the required runs. The training data are much smaller and less diverse than the original SimCSE setup, contradiction coverage is incomplete, and retrieval analysis is qualitative. Historical intermediate alignment values before the STS-B score-scale repair were excluded from the final analysis; the report uses only the final recomputed metrics.

\section{Conclusion}
Both SimCSE modes were successfully implemented and evaluated. Contrastive training substantially improved sentence representations over raw BERT. Independent dropout was essential for the unsupervised objective, while supervised SimCSE produced the strongest result at 82.29 dev and 78.32 test Spearman. The selected model was successfully published to Hugging Face and reproduced exactly after reload.
